# 快速入门指南

## 第一次使用？按照以下步骤操作：

### 步骤1: 安装依赖

```bash
pip install -r requirements.txt
```

**注意**: Windows用户可能需要额外安装PyAudio：
```bash
# 方法1: 使用conda (推荐)
conda install pyaudio

# 方法2: 下载wheel文件
# 访问 https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio
# 下载对应Python版本的.whl文件
# pip install PyAudio-xxx.whl
```

### 步骤2: 测试信号处理功能（可选）

在开始实际测距前，建议先测试信号处理是否正常：

```bash
cd common
python test_signal.py
```

如果看到类似输出说明功能正常：
```
测试1: Chirp信号生成
==================================================
Chirp A: 4000Hz -> 6000Hz
  长度: 24000 采样点
  持续时间: 0.500 秒
...
```

### 步骤3: 准备两台设备

需要准备：
- 两台电脑（或笔记本/手机）
- 每台都有麦克风和扬声器
- 连接到同一个Wi-Fi网络

### 步骤4: 查找IP地址

在**锚节点**设备上查看IP地址：

**Windows:**
```cmd
ipconfig
```
查找"IPv4 地址"，例如: 192.168.1.100

**Mac/Linux:**
```bash
ifconfig
# 或
ip addr show
```
查找类似 192.168.x.x 的地址

### 步骤5: 启动锚节点（设备A）

**方法1 - 使用启动脚本:**
- Windows: 双击 `start_anchor.bat`
- Mac/Linux: `./start_anchor.sh`

**方法2 - 手动启动:**
```bash
cd anchor_node
python anchor.py
```

然后：
1. 点击"启动服务器"按钮
2. 等待连接提示

### 步骤6: 启动目标设备（设备B）

**方法1 - 使用启动脚本:**
- Windows: 双击 `start_target.bat`
- Mac/Linux: `./start_target.sh`

**方法2 - 手动启动:**
```bash
cd target_device
python target.py
```

然后：
1. 在"服务器IP"框输入锚节点的IP地址（步骤4查到的）
2. 点击"连接服务器"
3. 看到"已连接"提示

### 步骤7: 开始测距

在锚节点设备上：
1. 点击"开始测距"按钮
2. 两台设备会自动播放和录音
3. 几秒后会显示测距结果

### 步骤8: 测试不同距离

将两台设备放置在不同距离：
- 建议从1米开始测试
- 逐步增加到2米、3米、5米等
- 每个距离测量5次以上
- 记录结果分析误差

## 常见问题快速解决

### 问题1: "pip install失败"
**解决**: 
```bash
# 使用清华镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题2: "无法连接服务器"
**检查**:
- [ ] 两台设备在同一Wi-Fi网络？
- [ ] IP地址输入正确？
- [ ] 防火墙是否阻止端口20000？

**Windows防火墙设置**:
1. 控制面板 → Windows Defender 防火墙
2. 高级设置 → 入站规则 → 新建规则
3. 端口 → TCP → 20000 → 允许连接

### 问题3: "听不到声音/无法录音"
**检查**:
- [ ] 音量是否合适（50-80%）？
- [ ] 麦克风是否被其他程序占用？
- [ ] 系统音频设备是否正常？

**测试方法**:
```python
# 运行Python测试麦克风
import pyaudio
p = pyaudio.PyAudio()
print(f"音频设备数量: {p.get_device_count()}")
for i in range(p.get_device_count()):
    info = p.get_device_info_by_index(i)
    print(f"{i}: {info['name']}")
```

### 问题4: "测距误差很大"
**优化**:
1. 减少环境噪声
2. 调整音量到70%左右
3. 确保两设备间无障碍物
4. 修改config.py中的DEVICE_A_DISTANCE和DEVICE_B_DISTANCE参数（用尺子测量实际距离）

### 问题5: "程序卡住/崩溃"
**解决**:
1. 关闭其他音频程序（音乐播放器、视频会议等）
2. 重启程序
3. 检查Python版本（需要3.7+）

## 性能提升技巧

### 提高精度
1. 增加测量次数求平均
2. 在安静环境测试
3. 校准设备内部距离参数
4. 使用更高采样率（修改config.py中的SAMPLE_RATE）

### 提高刷新率
1. 减小录音时长（修改config.py中的RECORD_TIME）
2. 缩短chirp持续时间（修改DURATION）
3. 优化信号处理算法
